# Doel van het project  
Het doel van het project is om een bestelrobot te ontwikkelen voor het pretpark Lakeside Mania. Deze robot moet bestellingen kunnen afnemen en afgeven.

# Werkwijze
We werken volgens het OTAP-proces en gebruiken deze branches.:  
- main voor productie > waar de versie wordt geupload die door de eindgebruiker wordt gebruikt
- acceptatie > voor het testen van de code door eindgebruikers voordat het naar productie gaat
- test > waar de functionaliteit wordt getest voordat het naar acceptatie gaat
- development > waar er samen wordt gewerkt aan de ontwikkeling

---------------------------------------------------------

- Elke wijziging gebeurt in een aparte feature branch  
- Voor elke wijziging wordt een merge request ingediend
- Code wordt lokaal getest voordat een MR wordt aangemaakt 
- Minimaal 1 teamlid voert een code review uit voordat er wordt gemerged
- Alleen de teamleider mag mergen naar productie
